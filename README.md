# FeatureClass Compare — QGIS Plugin

A QGIS plugin for comparing a reference and target Feature Class or Shapefile, including File Geodatabase (`.gdb`) and mixed-format comparisons.

- **Current package version:** 0.8.15
- **Minimum QGIS version:** 3.22
- **License:** GPL-2.0-or-later

## Repository contents

- [`FeatureClass_Compare/`](FeatureClass_Compare/) — installable QGIS plugin source folder.
- [`CHANGELOG.md`](CHANGELOG.md) — documented feature history.
- [`LICENSE`](LICENSE) — GNU GPL v2 or any later version.

## Build the QGIS upload ZIP

The QGIS Plugin Repository upload archive must contain the plugin folder as its top-level directory. Use the separately provided `FeatureClass_Compare_v0.8.15_QGIS.zip` release asset, or create it by zipping the `FeatureClass_Compare` folder itself (not the entire GitHub repository).
